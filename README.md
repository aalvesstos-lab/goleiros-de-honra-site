# Goleiros de Honra — site em HTML

Site institucional da escola de goleiros **Goleiros de Honra** (@goleirosdehonra).

- `index.html` — site completo em um único arquivo (abre direto no navegador; fontes carregam do Google Fonts, WhatsApp exige internet).
- `fonte/` — código-fonte (React + Tailwind) usado para gerar o `index.html`.

Para publicar no GitHub Pages: Settings → Pages → Deploy from branch → `site-html` / root.
